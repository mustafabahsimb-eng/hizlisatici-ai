Seltigo bağlantı kodu — yazılımcı kurulumu

Bu sayfa, sitesini Seltigo'ya iki yönlü bağlamak isteyen satıcının yazılımcısı içindir. Kurulum bir kez yapılır; sonra her şey kendiliğinden işler:

  • Seltigo → site: Seltigo'da eklenen / güncellenen ürün, stok değişikliği ve başka kanaldaki satış sitenize webhook (imzalı HTTP isteği) olarak gelir.
  • Site → Seltigo: Sitenizdeki satış ve stok değişikliği REST API ile Seltigo'ya bildirilir; stok tek merkezden yönetilir ve tüm pazaryerlerine (Trendyol, Hepsiburada, Amazon, Etsy …) ve Seltigo mağazasına yansır.
Satıcı önce Seltigo panelinde 🌐 Sitemi Bağla sayfasında sitesini doğrular, sonra "Seltigo bağlantı kodu" bölümünden API anahtarını (slt_live_…) ve webhook adresini girince imza anahtarını (whsec_…) alır. İkisi de yalnız bir kez gösterilir.

1. Kimlik

Her isteğe başlık ekleyin: Authorization: Bearer slt_live_…. Adres: https://ytucdrrgxsjhrqmaxckt.supabase.co/functions/v1/site-api. Sınır: bağlantı başına dakikada 120 istek. Gövdeler JSON; hatalar {"error":{"code","message"}}.

2. Uç noktalar

İstekNe yapar
GET /pingAnahtarı dener; mağaza adı ve adresi döner.
GET /products?limit=&offset=&updated_since=Ürünler (id, sku, gtin, ad, açıklama, fiyat, stok, görseller, seçenekler, mağaza adresi). updated_since ile yalnız değişenler (silinenler deleted: true).
GET /products/{id}Tek ürün.
POST /productsÜrün oluştur: { name, description, price, stock_qty, sku, gtin, brand, category, images: [https…], variants: [{ sku, gtin, stock_qty, attributes: { "Beden": "M" } }], url } ya da { products: [...] } (en fazla 100). Aynı barkod / SKU / ürün adresi varsa yeni ürün açılmaz, güncellenir. Ürün Seltigo mağazasında yayına girer.
PATCH /products/{id}{ name?, title?, description?, price?, cost?, stock_qty?, sku?, gtin? }
DELETE /products/{id}Ürünü kaldırır (pazaryeri ilanları da kapanır).
POST /stock{ items: [{ sku | gtin | product_id, variant_sku?, quantity }] } — stok miktarını yazar; tüm kanallara yansır.
POST /ordersSitede satış: { external_order_id, items: [{ sku | gtin | product_id, variant_sku?, quantity, price }], currency, customer: { name, email, phone, address, city, district, zip } }. Ortak stok düşer, pazaryerlerine yansır. Aynı sipariş numarası ikinci kez sayılmaz.
GET /orders?since=Seltigo'daki diğer kanalların (pazaryerleri, Seltigo mağazası) siparişleri.

3. Webhook (Seltigo → site)

Gövde: { "id", "event", "created_at", "data": {...} }. Başlıklar: X-Seltigo-Event, X-Seltigo-Delivery, X-Seltigo-Signature: sha256=<HMAC-SHA256(imza anahtarı, ham gövde)>. İmzayı ham gövde üzerinden doğrulayın ve 2xx dönün; 2xx gelmezse 1 dk, 5 dk, 30 dk, 2 sa, 12 sa, 24 sa sonra tekrar denenir.

Olaydata
product.created / product.updatedproduct_id, sku, gtin, name, price, stock_qty, stock_status — tüm ayrıntı için GET /products/{id}
product.deletedproduct_id, sku
stock.updatedproduct_id, sku, stock_qty, stock_status
order.createdorder_id, channel, product_id, variant_id, quantity, price, currency (başka kanaldaki satış)
pingPanelden "Deneme gönder".

Sitenizden API ile yaptığınız değişiklik size webhook olarak geri gönderilmez.

4. Hazır kod

İndirin: seltigo.php (PHP 7.4+, WooCommerce kancaları hazır) · seltigo.js (Node.js 18+).
